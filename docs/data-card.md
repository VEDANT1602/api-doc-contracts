# Data card

Fourteen authored source mutations operate on three fictional public Python functions and a structured documentation manifest. Code strings are parsed but never imported, evaluated or executed. Targets are top-level declared functions, literal exports, parameter kinds, defaults, annotations, async status and return annotations. Module control flow referencing exports, conditional public functions, decorators and global-export declarations require manual review. Function-local variables named __all__ are not module exports. Runtime behavior, classes and arbitrary export forms remain unestablished. Contract pass counts describe these fixtures, not natural-language documentation quality or universal compatibility.

All fixtures were generated specifically for this independent project. No upstream dataset, weights, media or result numbers were imported.
